## What these licences do NOT cover

This is the part that actually matters for a travel business, and it is not a
copyright question.

**Identifiable people.** Neither licence includes a model release. Using a
recognisable face to advertise a service can imply that person endorses it.
Every image below was checked for this, and any photo containing a
recognisable face was rejected rather than used. If you add images later,
apply the same test.

**Trademarks and logos.** A licence to a photograph is not a licence to a
brand mark inside it. Shots containing readable signage were rejected.

**Neither licence permits** reselling the files as stock, or redistributing
them outside a project like this one.

## If you add media later

1. Use Pexels, Mixkit, Unsplash or Pixabay, and confirm the licence allows
   commercial use without attribution.
2. Open the image full size and check for recognisable faces and readable
   logos. Reject rather than crop if in doubt.
3. Confirm the photo actually shows the place you are captioning. Stock search
   relevance is poor: a search for "Rajasthan" returns the Golden Temple, which
   is in Punjab, and a search for "Sentosa" returned the Palm Jumeirah in Dubai.
4. Download the file and serve it from `public/assets/`. Do not hotlink.
5. Add a row to the table above with the id and source URL.
